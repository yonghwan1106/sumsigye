# L2 후보 확장 — 사전 등록 (2026-10-26)

이 문서는 새 후보를 평가하기 **전에** 커밋한다. 커밋 뒤에 정한 것은 아래 「결과」 절에만 쓰고, 위 규칙은 고치지 않는다.
이유: 사건 26건(정확 12·구간 14)에서 모수(로그정규) 모형이 꼬리·위치를 과대추정한다(`docs/L2_diagnosis.md`).
평가 전에 이미 알려진 값(현재 /lab): LOO pinball 평균 M0 0.554 · M1 0.582 · M2 0.593 · 고정 2시간(B0) 0.437 · 관측 경험분위(B1) 0.383시간.

## 1. 후보 집합 (5개, 모두 결과 표에 남긴다)
| id | 정의 | 적합에 쓰는 사건 |
|---|---|---|
| M0·M1·M2 | 기존 그대로(로그정규 AFT, 구간·오른쪽 중도절단 우도, `pipeline/fit_restore.py`) | 정확·구간·오른쪽 |
| E0 | 정확 사건 지속시간의 경험분포. 정렬한 x(1)…x(n) 사이 n−1개 칸에 질량 1/(n−1)씩 균등(구간 선형 보간 CDF). 분위수 = `numpy.quantile(method="linear")` → **분위 예측은 B1과 구성상 같다**(B1을 「전체 분포로 쓰는 모형」으로 만든 것; 새 조정값 없음). n = 1이면 그 점의 점질량 | 정확만 |
| NP | Turnbull NPMLE(비모수 최대우도, EM). 관측 구간: 정확 [t,t] · 구간 [l,u] · 오른쪽 [l,∞). 최내곽(Turnbull) 구간에 질량, 시작 = 균등, 갱신 p_j ← (1/n)Σ_i α_ij p_j / Σ_k α_ik p_k, 멈춤 = max|Δp| < 1e-10 또는 20,000회. 질량 < 1e-12인 구간은 버리고 다시 정규화. 유계 구간 안의 질량은 균등하게 펼치고, 무계 구간 [l,∞)의 질량은 l에 점질량(Efron 꼬리 관례) | 정확·구간·오른쪽 |

결정론: 난수 없음(EM 시작값 고정). 시드·사건표·가구 설정은 바꾸지 않는다.

## 2. 선택 기준 (지금과 같음)
- 사건 단위 LOO: 정확·구간 사건 i를 하나씩 빼고 다시 적합 → **정확 사건 12건**에서 pinball(q = 0.5·0.8·0.9) 평균. 구간 사건은 P80 적중/빗나감/판정 불가(지금과 같음).
- 최소 평균 pinball의 2% 안쪽이면 단순한 쪽. **단순 순서(사전 고정)**: M0 < M1 < M2 < E0 < NP(추정하는 양의 수: 2 · 3 · 5 · 정확 사건 수 · 질량 있는 Turnbull 구간 수).
- B0·B1·B2는 지금처럼 기준선 행(선택 후보 아님).

## 3. 배정 엔진이 쓰는 분포
- 고른 모형의 **전체 분포**를 지금과 같은 방식으로 쓴다: 경과 e 조건부 생존 S(e+t)/S(e) · 조건부 분위수(R_q = P80, 칸 표본 적음이면 P90) · 부분기대값 E[(T−e−x)⁺ | T>e] · 119 레인 판정.
- E0·NP는 칸(원인군×야간)이 없는 전체 분포 1개(M0처럼, `small_cell` = false).
- 경과가 분포 끝을 넘으면(S(e) < 1e-12) 지금처럼 경과 0의 전체 분포로 되돌린다.
- L4 평가의 배정기 분포 = 지금처럼 **사건 j를 뺀 LOO 적합**(고른 모형). 시나리오 3건 화면도 지금처럼 그 사건을 뺀 LOO 적합.
- 고른 모형이 M0~M2면 엔진·파일 형식은 그대로. E0·NP면 조각 균등 분포(`kind: "piecewise"`, [a, b, 질량] 목록, 시간 단위)를 더한다 — 계산식만 늘리고 엔진 규칙은 바꾸지 않는다.

## 4. 바꾸지 않는 것
시나리오 시드(소규모 1~200·광역 1001~1200·민감도·LLM 30개)·가구 생성기·참값 뽑기(LOO 짝 부트스트랩)·엔진 가정값(`DEFAULT_PARAMS`)·비교 방법(R1·R2·R3·A1 고정 2시간·ORACLE)·채점·부트스트랩(2,000회 시드 7, 민감도 1,000회)·AI 챗봇 단독 프롬프트·모델·max_tokens.

## 5. 결과를 다루는 규칙
- 결과가 고정 2시간(B0)보다 나빠도 **더 조정하지 않는다**(후보·관례·선택 기준을 다시 고르지 않는다).
- 모든 후보 행(M0·M1·M2·E0·NP)과 기준선 행을 `data/eval/l2_results.json`·/lab에 싣는다.
- 배정 사다리: A1(고정 2시간) − 숨시계 짝 차이 95% 구간이 0보다 크면 그 규모에서 「복구시간 모형이 배정을 개선」, 0을 포함하면 「차이를 확인하지 못함」, 0보다 작으면 「고정 2시간이 더 나음」으로 쓴다(소규모·광역·전체 각각).
- 복구 분위 입력이 바뀌면 AI 챗봇 단독 기준선(30개 × 모델 2)을 같은 입력으로 다시 돌린다.

## 6. 시험(구현 정확성, 평가 아님)
`python pipeline/fit_restore.py --selftest`에 NP 시험 추가: ① 정확 사건만이면 NPMLE = 경험분포(질량 차 < 1e-9) ② 로그정규(μ 0.8, σ 0.7) 2,000개(구간 20%·오른쪽 중도절단 섞음, 기존 selftest와 같은 생성)에서 |F̂(t) − F(t)| < 0.04, t = 1·2·3·4·6시간 ③ EM 로그우도 감소 없음. TS 조각 균등 분포 함수는 Python 계산값과 대조(`tests/survival.test.ts`).
